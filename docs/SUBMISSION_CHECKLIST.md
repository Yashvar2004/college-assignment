- [x] Dashboard counters, events, alert queue, map and activity
- [x] ANPR validation, normalization, persistence and deduplication
- [x] Watchlist management APIs and representative synthetic data
- [x] Persisted WebSocket alerts and response lifecycle
- [x] Ordered multi-camera movement route and explicit route disclaimer
- [x] Audit API/UI, migrations, seed, simulator, OpenAPI
- [x] Dockerfiles, Compose, health checks and volumes
- [x] Backend workflow tests, frontend API smoke tests and CI
- [x] Architecture/ER diagrams, security, scale and demo docs
- [x] No real secrets, credentials, private footage or personal data

## Manual before sending

- [ ] Run Docker validation on a host with Docker Desktop
- [ ] Capture final screenshots
- [ ] Record the exact demo script; upload through the chosen submission channel
- [ ] Add candidate name, email/phone, GitHub repository URL, hosted URL and recording URL
- [ ] Rotate any hosted credentials and restrict demo ingress
- [ ] Review git diff; commit and push only after explicit owner approval
